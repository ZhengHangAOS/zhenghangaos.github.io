## 为什么搭建这个网站？

在传统的学术领域，研究成果往往被封存在一篇篇冰冷的 PDF 文献中。但我始终相信，**科学不仅需要严谨的推导，更需要具象化的感知。**

搭建这个网站的初衷非常纯粹：

- **学术的“可视化”表达**：流体力学、非线性动力学、涡度方程……这些写在黑板上的公式，不应该只是枯燥的字符。我想利用现代前端技术（如 3D 渲染与流式交互），让复杂的地球科学现象变得触手可及。
- **打破学科壁垒的尝试**：作为一名**大气与海洋科学**的学生，我同样对**计算机科学与深度学习**怀有热情。这个网站是我将气象数值模拟、统计 casual 机制与前沿 AI 算法（如 MLP、DCGAN）进行交叉融合的试验场。
- **纯粹的学术自留地**：在这里，我追求干净的排版，硬核的公式推导，和最纯粹的科普展示。

## 技术栈 & 资产致谢

本站完全基于 **GitHub Pages** 静态托管，拒绝臃肿的框架，追求极致的加载速度与原生质感：

- **核心解析**：利用 `marked.js` + `highlight.js` 打造了纯前端的 Markdown 文章加载引擎。
- **数学公式**：集成 `KaTeX` 组件，完美渲染学术论文级的流体方程组。
- **交互动力**：全原生 JavaScript 驱动，搭配精心调校的毛玻璃（Glassmorphism）视觉特效。
