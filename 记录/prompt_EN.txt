# Project Prompt — Zhenghang’s AOS Lab

## Project Overview

Create a highly atmospheric, interactive, visually immersive personal website called:

# “Zhenghang’s AOS Lab”

The website is a static frontend project primarily built with:

- HTML
- CSS
- JavaScript

Additional lightweight libraries are allowed when necessary, especially:

- Three.js (strongly recommended)
- GSAP (optional for transitions/animations)

Avoid overly heavy frameworks or backend systems.
The website should feel like a hybrid of:

- a scientific visualization lab
- a digital observatory
- a planetary atmosphere research station
- an interactive world

This is NOT a traditional blog template.
Do NOT generate generic “developer portfolio” layouts.

The core thematic keywords are:

- Planet
- Atmosphere
- Ocean
- Fluid
- Circulation
- Climate
- Space
- Quietness
- Floating
- Scientific imagination

The visual feeling should be:

- calm
- immersive
- spatial
- atmospheric
- elegant
- slightly futuristic
- semi-realistic
- not cartoonish
- not cyberpunk

The site should feel alive, like an inhabitable digital planet.

---

# General Design Language

## Overall Style

Use:

- glassmorphism
- soft neumorphism
- depth
- layered shadows
- floating motion
- translucent panels
- smooth transitions
- subtle parallax
- volumetric feeling

Avoid:

- flat minimalist corporate UI
- sharp edges
- overly saturated colors
- fast aggressive animations
- neon cyberpunk aesthetics

---

# Color System

## Night Mode

Main tones:

- deep navy blue
- dark teal
- atmospheric cyan
- faint aurora green
- dim white glow

The night mode should resemble:

- upper atmosphere
- stratosphere at night
- planetary twilight
- deep ocean atmosphere

## Day Mode

Main tones:

- cold white
- pale sky blue
- cloud gray
- soft warm sunlight
- subtle oceanic cyan

Weather should affect background tone slightly.

---

# Motion Language

Animations must feel:

- slow
- smooth
- floating
- inertial
- fluid-like

Avoid snappy UI animations.

Recommended transition timing:

0.5s ~ 1.2s

Use easing curves with inertia feeling.

Objects should subtly:

- float
- rotate slowly
- react to mouse movement
- drift slightly

The whole website should feel like it exists inside an atmosphere.
