# 项目总 Prompt —— Zhenghang’s AOS Lab

## 项目概述

创建一个高度沉浸式、具有空间感、支持 3D 交互的个人网站：

# “Zhenghang’s AOS Lab”

网站主要基于：

- HTML
- CSS
- JavaScript

进行构建。

允许使用少量轻量级库，尤其推荐：

- Three.js（强烈推荐）
- GSAP（可选，用于动画与转场）

避免使用过于复杂、重量级的框架与后端系统。

整个网站应当像是：

- 一个科学可视化实验室
- 一个数字化行星观测站
- 一个行星大气研究空间
- 一个可交互的数字世界

这不是传统意义上的博客网站。

不要生成：

- 普通开发者作品集
- 模板化个人主页
- 商业化企业风格布局

网站的核心主题关键词：

- Planet（行星）
- Atmosphere（大气）
- Ocean（海洋）
- Fluid（流体）
- Climate（气候）
- Circulation（环流）
- Space（宇宙空间）
- Quietness（静谧）
- Floating（漂浮）
- Scientific imagination（科学想象力）

网站整体气质应当：

- 安静
- 沉浸
- 具有空间感
- 富有大气氛围
- 优雅
- 略带未来感
- 半写实
- 不卡通
- 不赛博朋克

整个网站应该像一颗“活着的数字行星”。

---

# 整体设计语言

## 总体风格

使用：

- 毛玻璃（glassmorphism）
- 轻拟物风格（soft neumorphism）
- 深度感
- 分层阴影
- 漂浮运动
- 半透明面板
- 平滑过渡
- 轻微视差
- 具有体积感

避免：

- 纯平面企业风
- 尖锐边角
- 高饱和霓虹色
- 速度很快的动画
- 赛博朋克视觉风格

---

# 色彩系统

## 夜间模式

主色调：

- 深海军蓝
- 深青蓝
- 大气青色
- 微弱极光绿色
- 暗白色辉光

夜间模式应当像：

- 夜晚的高层大气
- 平流层
- 行星暮光
- 深海般的大气层

---

## 白天模式

主色调：

- 冷白色
- 浅天蓝
- 云层灰
- 柔和暖阳色
- 淡海洋青色

天气系统应轻微影响背景颜色。

---

# 动画语言

所有动画应当：

- 缓慢
- 平滑
- 具有漂浮感
- 带有惯性
- 像流体一样自然

避免：

- 迅速、突兀的 UI 动画

使用具有惯性感的 easing 曲线。

元素应轻微：

- 漂浮
- 缓慢旋转
- 对鼠标产生反应
- 缓慢漂移

整个网站应当像存在于一个真实的大气层中。

## 左侧区域
显示一个漂浮天气动画系统，动态的显示天气的浮动的动画图形，要有浮动感、立体感。我想制作成拟物真实风格的，比如说云、太阳/月亮，拥有动效，就像ios的天气软件里的一样，或者早期安卓的天气软件那个动画效果。
天气属于hero页的虚构星球。天气包括：晴天，阴天，多云，雨天，雷暴，雪天，雾霾，沙尘暴。
每种天气都有：动态拟物图形：太阳/月亮，漂浮云层，雨线，闪电，飘雪，树叶，沙尘粒子。具体比如：晴天就是一个太阳/月亮/一堆星星，阴天是一堆云，多云是一两朵云遮住太阳/月亮，雨天是云和雨线下落。
风格：轻拟物、偏真实，动态，漂浮，有体积感。鼠标移动上去会变大一点。
天气每次页面加载随机生成。白天/黑夜模式会影响。
